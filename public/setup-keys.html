Hearth setup keys

Your browser generates these keys. Nothing is sent anywhere. Copy each value into Vercel → your project → Settings → Environment Variables, then redeploy. Keep them private; don't post them anywhere.

Generate only once.
Changing APP_ENCRYPTION_KEY later makes saved household Gemini keys unreadable. Changing the VAPID keys means each device has to turn notifications on again. Reloading this page creates new random values.
